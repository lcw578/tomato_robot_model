# 番茄采摘机器人整机 MuJoCo 模型（tomato_picker.xml）

> 生成日期：2026-09-28。由三路资产拼接而成，生成脚本在 `/data/robot_assembly/`。
> 快速预览：`python3 -m mujoco.viewer --mjcf=/data/robot_assembly/model/tomato_picker.xml`

## 模型结构

```
world
├── chassis（静态，307 个 CAD 零件：车体/风琴罩/升降平台/控制箱/传感器/基座盘）
│    ├── 10 个轨轮（hinge，绕世界 y 轴）
│    │    ├── act_left / act_right      主动轮（velocity 执行器，ctrl=rad/s）
│    │    └── 其余 8 个从动轮（自由，damping=0.001, frictionloss=0.02）
├── arm_base_mount（静态，官方 i5 base 网格，位于 (2,4,-704)mm，z 朝下）
│    └── shoulder_Link → upperArm → foreArm → wrist1 → wrist2 → wrist3
│         （AUBO i5 官方 6 连杆，行程 ±3.0543 rad，速度上限 J1-3=2.618、J4-6=3.1416 rad/s）
│         └── gripper base_link（基线 gripper_scene.xml 子树原样移植 + 相机/转接板 geom）
│              ├── gear_link（hinge，range ±[0.4744,0.4632]）
│              ├── right_finger_link / left_finger_link（slide，equality 耦合到 gear）
```

总质量 111.2 kg（车体按塑料密度 1.2 g/cm³ 估算 90.3 kg；臂为 AUBO 官方质量；夹爪为基线值）。

## 生成约定与决策

1. **坐标系与朝向**：CAD 装配体本身是颠倒建模的（轮朝上、臂朝下）。模型在 worldbody 用根 body `machine`（quat=180°绕x，pos z=0.0664）整体翻转：**轮子落地（主动轮底面 z=0）、车体在轮上、升降平台在顶部、机械臂竖直向上**。地面为纯视觉平面（contype=0，无碰撞）。世界 z=0 在主动轮接地点。
2. **臂安装**：CAD 中的臂是风格化简化模型（非 i5 真实几何，已确认并整体删除，27 个零件）。真实 i5 链按 CAD 基座盘（part_331 的位置 = 设计安装位）安装：法兰面 z=-704mm、朝下、J1 零位朝向任意（被 q1 吸收）。
3. **夹爪安装（2026-09-29 定稿）**：通过**腕部相机打印件**（362 L形支架 + 371 垫圈）装在真实法兰上——**轴对轴、面对平面**：打印件顶面（体坐标 z=50.95mm，圆盘面以工具轴为中心）贴合法兰环面（wrist3 系 y=44.95mm，环带半径 18.1~31.9mm 以工具轴为中心），夹爪随之整体下移 7.6mm（法兰到夹爪安装面的打印件厚度）。**风格化腕部复制件 358/360/361 已删除**（真实臂自带该部分）；相机组件（363~369）仍在 362 支架臂上。弧形贴片陷阱：法兰环面与 362 顶面在 STL 里都按弧片细分，**顶点质心≠环心**——按质心对质心会把整机横向偏 (−9.1, −23.9)mm，必须按轴对轴+面对平面装。
4. **夹爪基线红线未动**：equality 乘数、限位、5 对 exclude 原样移植；开口(mm)=31.92−42.0×q_gear；ctrl>0 为闭合。已验证耦合比偏差 <1.5%。
5. **新增 exclude**：chassis↔每个轮子（10 对，轮子要在支架内自由转）；arm_base_mount↔shoulder（官方两网格在关节处设计性重叠 6.5mm）。注意：本 MuJoCo 版本默认**不过滤**父子 body 碰撞。
6. **删除的环境/冗余零件**：整机里 47 个与基线夹爪重复的实体、2 根种植架管子（339/346，环境道具，与臂互穿）、风格化臂 27 件、肩壳内螺钉等。
7. **轮子执行器**是占位 velocity 伺服（kv=8，ctrl±40 rad/s）；臂伺服 kp/kv 是占位值（1500/900/300 档），forcerange 按 J1-3=±80、J4-6=±40 N·m——**装车后需要重调**。

## home 姿态与腕部说明

- **真实法兰在 wrist3 的 +y 端面**（官方 ee_site 证据；-z 端面是 AUBO 铭牌盖）。法兰环面以工具轴为中心、半径 18.1~31.9mm、平面 y=44.95mm。
- **腕部相机打印件**（362 支架 + 371 垫圈）**夹在法兰与夹爪之间**并携带相机；相机组件（363~369）同。 mounting 详见上文第 3 条（轴对轴+面对平面）。
- **重要（2026-09-29）**：这些零件的网格已**烘入夹爪体坐标系**（`model/meshes_baked/*_baked.stl`，geom pos=0）——此前用 inv(T_VG) 变换的 geom pos 在法兰修正改变体朝向后全部过期失效，零件散落 0.5~2.5m（"飞出去的零件"的根源）。改夹爪安装时重跑烘焙脚本即可。另注意 MuJoCo 会把网格重定心到主惯性系：**世界坐标 = geom_xpos + geom_xmat @ mesh_vert**（mesh_pos/mesh_quat 已烘进 geom 位姿，勿再乘一遍，否则测量全错）。
- home keyframe = `shoulder=90°, upperArm=-46°, foreArm=46°, wrist1=-90°, wrist2=-92°`（工作位：臂前伸、法兰垂直朝下、夹爪离大臂轴 732mm 无遮挡、零接触）。注意臂向 +x 折叠会撞传感器支杆（真实约束）。
- 新增 exclude：gripper base_link ↔ wrist1/2/3（末端件贴法兰安装）。
## 配色与外观

**机械臂外观 = 官方 DAE 材质分组双色涂装**（2026-09-28）：`split_dae.py` 把官方 DAE 按材质组拆成每个连杆 2~3 个网格（m1=管身白、m2=关节壳 AUBO 橙 0.99/0.37/0.06、none=内件深灰），每个连杆 = 原 STL 隐形碰撞体（group 3, rgba 0）+ DAE 组可见几何（contype=0）。注意：① DAE 的 <vertices> input semantic 是 POSITION 不是 VERTEX；② DAE 自带材质是黑色占位，颜色是指定的；③ m1/m2 分组语义逐连杆核实过（upperArm 验证：m1=管身、m2=肘壳）。

其余部件配色（指定方案，无真实贴图来源）：

轮子橡胶黑、车体中灰、风琴罩深灰、控制箱深灰、升降平台浅灰、传感器杆/头橙色、夹爪铝银、相机黑、地面深灰（纯视觉）。配两盏平行光。要改颜色直接改 `phase_c_build.py` 里的 `CHASSIS_COL` 和各 `rgba=` 字段重跑即可。

## 已验证

- 零位（臂竖直下垂）零接触；3s 伺服保持漂移 2.6 mrad
- 夹爪耦合比 r=-0.0207/l=-0.0213（基线 -0.020995/-0.020999，偏差 <1.5%）
- 轮子速度伺服精确跟踪；从动轮自由
- 折叠自碰：wrist1 会碰到夹爪后壳（真实约束，机械上存在）
- home 位 3s 保持漂移 0.33 mrad；夹爪耦合比偏差 <1.5%

## 已知限制

- 车体焊死在世界系（要整车移动需释放 chassis 并给轮子摩擦/轨道约束）；地面为纯视觉，未参与碰撞
- 升降平台为静态（CAD 快照高度）
- 质量 = 塑料密度估算（臂除外）；轮子惯量按均质圆柱
- 命名：mesh 资产 `v_*`/`w_*`/`a_*`/`g_*`/`c_*`；**geom 名**：车体 `v_part_*`、轮 `w_*`、臂 `a_*`、相机 `cam_*`，夹爪沿用基线原名（`base_link_mesh_*`/`gear_link_mesh_*`/`*_finger_link_mesh_*`）
- **零星悬浮件清理（2026-09-28）**：16 个小散件已删（风格化臂/夹爪螺钉 338/343/345/350，控制箱周围浮螺钉 288/269/276/271/285，浮板 103/106/139，尘点 158/165/193/200——判据：小零件距任何大零件表面 >15mm）；365/369（相机支座杆件）改挂相机组件。part_328（传感器支杆顶端探头）为真实部件，保留——细杆深色远看像悬浮，勿删
- part_339/346（种植架管）如需环境可单独加回场景
- 小导向轮（Ø61 导轨侧压辊）落地后下探 2.3mm，属导轨车型几何，平地姿态下正常
